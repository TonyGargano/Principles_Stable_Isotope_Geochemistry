# Science in the Queue modules

Interactive figures embedded in the Science in the Queue posts on [garganogeochemistry.com](https://garganogeochemistry.com/science-in-the-queue/). Each file is self-contained HTML. A `#card-…` hash shows one card alone for embedding, and each page posts its height to the parent page so the frame can size itself.

## Inhale, Exhale (body water and respiration)

| File | Cards |
|---|---|
| `respiration_breath_holds.html` | `#card-slope` breath-hold residual O2 slope, `#card-uptake` O2 used and taken up, `#card-co2` breath CO2 against the body water model across theta |
| `respiration_body_water.html` | `#embed` the steady-state body water mass balance with six animal archetypes |
