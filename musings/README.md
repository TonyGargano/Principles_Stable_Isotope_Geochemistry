# Musings modules

Interactive figures embedded in the Musings posts on [garganogeochemistry.com](https://garganogeochemistry.com/notes/). Each file is self-contained HTML. A `#card-…` hash shows one card alone for embedding, and each page posts its height to the parent page so the frame can size itself.

## Tutor, Not Oracle

|---|---|
| `tutor_not_oracle_modules.html` | `#card-rct` the Bastani et al. result, `#card-fork` the prompt fork, `#card-design` design the deployment |
